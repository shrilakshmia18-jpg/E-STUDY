# 📚 E-STUDY - Educational Learning Platform

E-STUDY is a web-based educational platform developed using PHP and MySQL. It helps manage students, courses, branches, and subjects in one place.

### ✨ Features
- Add / Manage Branches and Subjects
- Chapter-wise content management
- User Authentication System
- Admin Dashboard
- Responsive UI

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Server: XAMPP / Apache

### 🚀 How to Run
1. Clone the repo: git clone https://github.com/shrilakshmia18-jpg/E-STUDY.git
2. Import database .sql file to phpMyAdmin
3. Place project in htdocs folder
4. Start Apache & MySQL in XAMPP
5. Run on localhost/E-STUDY
